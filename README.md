# 🎃 Little Pumpkin Design – Portfolio & Freelance Website

This repository contains the full source code for my personal portfolio and freelance website. To ensure a seamless, modern, and easily deployable architecture, the entire application is containerized using Docker, combining both the frontend and the backend into an **All-in-One** setup.

---

## 🛠️ Tech Stack & Architecture

The project is split into two main parts, orchestrated to run together flawlessly:

* **Frontend:** Developed with **Angular (Latest Version)**, TypeScript, and SCSS. It's built for speed, responsiveness, and a pixel-perfect user experience.
* **Backend / CMS:** Powered by **Strapi (Headless CMS)**, allowing dynamic content management for my portfolio projects, services, and blog posts.
* **DevOps / Deployment:** **Docker & Docker Compose** are used to package the Angular production build (served via Nginx) and the Strapi instance into a unified, lightweight environment.
