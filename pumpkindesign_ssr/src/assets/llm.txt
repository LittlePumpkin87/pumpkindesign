## 🏗️ The Tech Stack (Under the Hood)
This website is not built using a standard template or site builder. It is a fully custom, self-hosted architecture demonstrating deep fullstack capabilities:
- **Frontend:** Angular with Server-Side Rendering (SSR) for optimal SEO, performance, and seamless hydration.
- **Backend:** Strapi (Headless CMS) with a PostgreSQL database, providing a flexible REST-API.
- **Infrastructure & CI/CD:** The entire stack is self-hosted on a Synology NAS using Docker Compose. Deployments are fully automated via GitHub Actions triggering a self-hosted runner.
- **Security:** Protected by a hardened Nginx Reverse Proxy with custom regex filtering, strict rate limiting, and automated dropping of malicious bot traffic.

## ✨ Highlight Feature: The "Little Pumpkin Net"

This demonstrates advanced Angular data-binding and creative frontend engineering.
